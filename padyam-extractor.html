How to use
  1. Select the Parva.
  2. Select the Asvasa.
  3. Check the calculated HTML range.
  4. Click Generate PowerShell.
  5. Click Download .ps1.
  6. Run the downloaded PowerShell script on Windows.
The actual downloading is performed by PowerShell, not by GitHub Pages. This avoids the CORS restriction on andhrabharati.com.
